# cpuinfo-ds

A dataset of Linux `/proc/cpuinfo` dumps. It is used for testing [SHORKFETCH's](https://github.com/SharktasticA/shorkfetch) CPU interpreting functions. `/proc/cpuinfo` provides factual, anonymous information about a host's processor via interpreting CPUID. These dumps are gathered from online sources, my own work, or via donations. Given it is not creative work, it isn't subject to copyright, nor do I claim ownership of these.
